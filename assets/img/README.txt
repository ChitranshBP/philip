IMAGES
======

Drop photos in this folder using these exact filenames and they appear on the
site automatically. Any file that is missing falls back to a designed
placeholder, so the layout never breaks.

  hero-bg.jpg          Hero background. 2400 x 1400 px or larger, landscape.
                       IMPORTANT: the headline sits over the LEFT third of this
                       image, so choose a photo whose subject sits right-of-
                       centre and whose left side is calm (sky, wall, blurred
                       background). Warm, sunlit, real people — not stock
                       handshakes. Export as progressive JPEG, aim for < 400 KB.
                       Position is tuned in index.php via the
                       `object-[65%_center]` class if you need to nudge it.

  philip-portrait.jpg  Square portrait of Philip for the "A note from Philip"
                       section. 1000 x 1000 px minimum. Eye contact, smiling,
                       plain or softly blurred background.

Optional extras you may want later:
  og-image.jpg         1200 x 630 px, used when the site is shared on Facebook
                       or in a text message. Wire it up in the <head> of
                       index.php.
  favicon.png          512 x 512 px.

Tips
----
* Compress before uploading (squoosh.app is free and good).
* Real photos of Philip and real local clients always outperform stock.
* If you use a stock photo, keep the licence receipt on file.
